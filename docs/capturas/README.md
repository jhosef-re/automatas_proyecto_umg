# Capturas de pantalla

PNGs de las 8 pantallas de la app Swing, capturadas con
[`automatas.tools.CapturadorPantallas`](../src/automatas/tools/CapturadorPantallas.java)
(usa `paintAll` sobre `BufferedImage`, sin Robot ni X11, para evitar
que diálogos del escritorio contaminen la imagen).

| Archivo | Pantalla |
|---------|----------|
| `01_portada.png` | Portada con datos del curso |
| `02_menu.png` | Menú principal (8 opciones) |
| `03_crear_afd.png` | Crear AFD (modo 1 y modo 2) |
| `04_crear_gramatica.png` | Crear Gramática |
| `05_evaluar.png` | Evaluar Cadenas (con botón Convertir a…) |
| `06_cargar.png` | Cargar archivo `.afd` o `.gtk` |
| `07_guardar.png` | Guardar AFD o gramática |
| `08_reportes.png` | Reportes (Ver Detalle + Generar PDF) |

**Resolución:** 960 × 640 px · **Uso:** Manual de Usuario (Fase 8).
